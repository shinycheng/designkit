# DesignKit

面向电商运营的 AI 商品图生成平台。上传一张商品原图，换背景、配场景、按平台比例出图，主图、详情图、海报一次做完。

使用者不需要懂提示词：选分类、写一句商品特点，AI 看图从灵感库挑参考、合成提示词、出图。

## 功能

- **生成工作台**：选商品图 → AI 配提示词 → 选比例 → 核对花费提交，四步出图
- **AI 配提示词**：AI 读商品图，从灵感库按分类粗筛、细选、合成一条可编辑的提示词
- **灵感库**：一万五千余条提示词，按分类检索，每 12 小时自动同步更新
- **批量出图**：多张商品图 × 多条提示词任意组合；提交前显示预估花费并二次确认
- **比例护栏**：1:1 / 3:4 / 4:3 / 16:9 / 9:16，补白边保证产品不被裁剪
- **额度管理**：按用户分配额度、冻结结算防透支、余额不足一键向管理员申请
- **对外接口**：界面上能点的每一步都有对应接口，可接 ERP 等外部系统

## 技术形态

Go 后端 + Vue 3 前端 + PostgreSQL + Redis + Python 图像预处理服务，Docker Compose 部署，前端打包进后端镜像、单端口访问。
