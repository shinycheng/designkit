# ============================================================================
# 广告法违禁词词库（电商文案场景）
# ============================================================================
#
# 格式：一行一个词，UTF-8；# 开头是注释；空行忽略。
# 英文词一律写小写（匹配时对文本做 ASCII 小写化，NO.1 / no.1 都命中）。
#
# 来源与整理原则（详见同目录 LICENSE-sources.md）：
#   - 底子是 521xueweihan/advertising_law_checker（MIT）的极限词方法与示例词，
#     在其上按公开的《广告法》极限词汇总逐类扩充；
#   - houbb/sensitive-word（Apache-2.0）评估过：它的词库不区分「广告法」分类，
#     内置词偏涉政涉黄，电商文案会大量误报人名地名，因此**没有采用**；
#   - 只收广告法/违规营销相关的词，涉政涉黄一律不收。
#
# 宁缺勿滥——下面这些**刻意不收**，收了误报比漏报更伤人：
#   - 单字「最」：会把「最近」「最多可用」全标红。收的是「最X」常见组合。
#   - 裸「NO」「TOP」：会命中 NOTE、LAPTOP。收 no.1 / no1 / top1 / top.1。
#   - 「100%」：会命中「100%棉」这类合法成分标注。收「百分之百」「百分百」。
#   - 「一级」「甲级」「特级」「五星级」：能效、酒店、橄榄油等合法等级用语。
#   - 「治疗」「消炎」「杀菌」：合法器械/消字号产品的类目词。
#   - 「爆款」「秒杀」「清仓」「首发」：平台自己在用的活动词，单独出现不算违规。
#
# 命中不代表一定违规（同一个词在可证实的语境下可能合法），以平台审核为准——
# 界面上有这句提示，改词库时别把它当成「命中=违法」的判定器来加词。
#
# 规则会变：加词/删词直接改本文件（一行一词），重新编译即生效。
