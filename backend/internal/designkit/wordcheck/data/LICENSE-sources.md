# 词库来源与许可证

`adlaw.txt`（广告法违禁词，305 词）的来源说明。

## 用了什么

- **[521xueweihan/advertising_law_checker](https://github.com/521xueweihan/advertising_law_checker)**
  （MIT License，Copyright (c) 2019 削微寒）。
  取用的是它的**极限词检查思路和内置示例词**（最后一波 / 大品牌之一 / 第一 /
  独一无二 / 一流 / 仅此一次 等）。该项目本身只内置 9 个示例词、完整词表靠
  使用者自己粘贴，所以词库主体是在它的示例之上，按公开流传的
  《广告法》极限词汇总（法律条文口径的词语列表，不构成受版权保护的独创性汇编）
  逐类扩充整理的，扩充与取舍由本项目自行负责。

## 评估过但没用

- **[houbb/sensitive-word](https://github.com/houbb/sensitive-word)**（Apache-2.0）。
  它的词库文件（`dict_20231117.txt` 等，1.4 万余词）**不区分分类**，拆不出
  「广告法/违规营销」子集；内置词偏涉政涉黄，直接拿来在电商文案场景会大量误报
  人名地名。因此一个词都没有采用，仅在选型时评估过。

## 本项目的取舍

收词原则、刻意不收的词（裸「最」、裸「NO/TOP」、「100%」等）写在
`adlaw.txt` 文件头注释里，改词库前先读那一段。
