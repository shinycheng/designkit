# DesignKit × Claude Design 页面级提示词手册（v2）

> 原文由 monica 于 2026-08-15 提供。v3（同目录）在此之上定稿；冲突处以 v3 与《拍板增补》为准。
> 令牌对照表与 v3 3.2 完全一致，此处不重复。本文件保留的是 v3 引用的页面级细节原文。

## 使用总则

1. 模型 Fable 5；产品端一个项目，官网单开。
2. 每条提示词只做一屏；下一屏先说"沿用本项目已确认的外壳和工作台风格"。
3. 迭代优先级：点击元素评论 > 调节滑块 > 追加对话。
4. 中文；金额一律 `$`；花钱按钮旁标价；"取消"只用于关弹窗。

## 1. 应用外壳 S1（⚠ 68px 图标栏方案已被拍板增补作废，仅存档）

桌面：顶栏 54px（logo + 「DesignKit」字标 + 小标签「商品图」；右侧头像菜单）；左侧 68px 图标工具栏（生成工作台/灵感库/我的图片/个人资料 + 管理员分隔线下「商品图设置」；选中态图标变紫 + 2px 紫指示条 + soft 底；悬停 tooltip；1.75px 线性图标）；内容区页面底色，1440px 居中。移动 390px：顶栏保留 logo 与头像；底部 64px 导航（图标 + 11px 文字），管理员设置收进头像菜单。状态：余额不足全局提示条（警告 soft 底 +「可用余额不够了，还差 $X」+ 文字按钮「申请额度」）。

## 2. 登录页 S2

左 55% 舞台：大标题两行「商品图，运营自己出」/「AI 帮你配好提示词」；副标题「上传一次商品原图，换背景、配场景、按各平台要求出图。主图、详情图、活动海报一起做完，导出即可上架。」；15 平台标识球形环绕缓慢自转，衬标题下方偏右，球后紫色氛围光 rgba(124,107,255,.2) 半径大强度低；静态排列版（三行错落圆形徽标）做退路；左下信任句「出图前会先算一次预计花费，确认之后才开始跑，不会先斩后奏。」配小盾形/对勾图标。
右 45% 表单垂直居中：标题「登录 DesignKit」；邮箱、密码（可见性切换）；主按钮「登录」通栏；小字「没有账号？找管理员拿邀请码注册」。状态：字段错误（红描边 + 一句怎么办）、登录失败横条「邮箱或密码不对，再试一次」、登录中 loading。注册第二画面：邮箱 + 密码 + 邀请码 + 「注册」。
整体：页面底色上左上/右下两团极弱紫/青氛围光，不影响文字对比度。
迭代片段：平台球缩小 15% 转速减半；登录失败变体「密码改过了，登录状态失效，请重新登录」。

## 3. 生成工作台 S3（核心页）

studio 布局：中间画布 + 右侧 400px 固定配置区；窄屏配置区变抽屉，悬浮按钮「出图设置 · N 张」呼出。顺序：提示词在上、比例在下（2026-08-14 monica 亲自纠正过）。

【中间画布区】
1. 页头：小标签「商品图」/ 标题「生成工作台」/ 描述「上传商品图、挑一批提示词、选好出图比例，一次把要出的图排下去。」右上批次摘要「3 张商品图 × 4 条提示词 = 12 张」。
2. 横排三格数据卡：「本月出图 N 张」「花费 $X」「余额 $Y」+ 小字「花费按实际扣费统计，包含出图失败但已经计费的部分；张数只算还留在『我的图片』里的图。两者对不上是正常的。」
3. 「第一步 · 选商品图」：拖拽框「把图片拖到这里，或者点一下选文件」+ 辅助行「支持 JPG、PNG、WEBP、HEIC（苹果手机默认格式），单张不超过 20MB，可以一次选多张。」缩略网格衬底 #17191E、可移除、「上一轮出的图」角标、上传中 {percent}%、失败可重传。
4. 结果区空态：「出好的图会显示在这里」/「先在上面选商品图，再到右边写提示词、选出图比例，最后点『提交出图』。」+ 克制线条插画。
5. 提交后批次进度面板：头部（批次名/徽章八态：刚提交/准备中/生成中/结算中/全部成功/部分成功/失败/已停止；「已完成 {done}/{total}」；「成功 N · 失败 N · 已停止 N」）；等待提示「一张图大约要 20 秒。可以先去忙别的，这个页面会自己刷新；关掉网页也不影响出图。」+ 弱提示「网络有点不稳，正在重连…」；任务卡网格（缩略图生成中骨架屏 + 「第 {seq} 张」+ 徽章 + 「这一张扣了 $1」；hover「下载」「用这张继续生成」；失败卡「重试这一张」+「第 2 次尝试 · 最多能试 3 次」）；右上「停止排队」次级危险按钮；完成横幅三态（「这一批全部出好了。」/「这一批出好了 N 张，有 N 张没成功。」/「这一批已经停止排队了。」停止态追加「已经开始生成的那几张会跑完并照常扣费，图会保存在『我的图片』里。」）。

【右配置区 400px「出图设置」】
1. 「从灵感库带来的提示词」（仅带来时出现）：段落卡列表可移除 + 小字「出图时这些排在你手写的前面。不想要了就点『移除』。」
2. 「第二步 · 选分类、写商品特点，让 AI 配提示词」：说明「选一个大致分类，写一句商品特点，AI 会看着你传的商品图，从灵感库里挑 5 条参考，合成一条提示词。」分类下拉首项「全部分类（让 AI 自己判断）」+ 提示「不确定就选『全部分类』，AI 会自己看图判断该按哪一类挑。」「商品特点」多行 placeholder「例如：米白色针织开衫，秋冬新品，主打柔软亲肤，想要日系温柔的感觉」+ 辅助「写商品本身就行：材质、颜色、卖点、想要什么感觉。提示词交给 AI 写，你不用会写。」「不填也能推荐，填了更贴你的商品。」花钱主按钮「让 AI 推荐 · $0.09~$0.34」。运行态：按钮「AI 正在翻灵感库…」+ 阶段进度（判分类→粗筛→细选→合成）+「大概要 1~2 分钟（分类越大越久），别关这个页面。这一步只是想提示词，不出图、也不扣出图的钱。」结果卡「AI 给你的提示词」可编辑 +「这段可以直接改，改完再往下走。出图用的就是这一条，出 1 张图。」+「AI 看图判断这是『{分类}』，就按这一类挑的。觉得不对就换个分类再推荐一次。」+ 折叠「AI 参考了灵感库里这 5 条」（注「这 5 条只是推荐的依据，不会各出一张图。真正出图用的是上面那一条。」）+ 文字按钮「重新推荐」（标注会再次收费）。
3. 「第三步 · 选出图比例」：五个真实宽高比选择块（主图 1:1 / 详情竖版 3:4 / 横版 4:3 / 横幅 16:9 / 竖屏 9:16），角标「预估档位 2K」；说明「选好比例，我们会给商品图补上白边再出图，产品本身不会被裁掉。」
4. 「花费预估」卡：「这一批共 {count} 张」「每张 $1」「预计花费 $X」「当前可用 $Y（可用 = 余额 − 排队占用）」。四态：够（绿「余额够，可以提交。」）/ 不够（红「可用余额不够这一批，还差 $X。」+「可以少选几张再提交，或者点『申请额度』告诉管理员。」+ 按钮）/ 价格待确认（「这个比例的单价还没测出来，算不出总价。可以先少排几张试试，或者问一下管理员。」）/ 超上限（「一次最多提交 50 张，现在是 N 张。请少选几张商品图或提示词，分几批提交。」）。
5. 批次命名 placeholder「例如：夏季新款-白底主图」。
6. 通栏主按钮「提交出图」。

【窄屏 768 以下】配置区收抽屉；右下悬浮「出图设置 · 12 张」，右滑出，遮罩点击收起。

迭代片段（弹窗）：确认提交（「这一批共 12 张，预计花费 $12.00。提交之后就开始出图，钱会实际扣掉。」附注「提交后可以点『停止排队』拦下还没开始的那些；已经在生成的拦不住，会照常出图并扣费。」按钮「确认提交」/「再想想」）；停止排队（「还有 8 张没开始，停止后不再生成、也不扣费；正在生成的 4 张会跑完并正常扣费，图会保存在『我的图片』里。」按钮「确定停止」/「继续出图」）；重试（超时警告「上一次是超时——那张图很可能已经出来并且已经扣过钱了，只是结果没回到我们这里。要不要再花一次，请自己拿主意。」）；AI 推荐四个失败态内联提示按 i18n suggest.needAsset / failed / empty / timeout 原文。

## 4. 灵感库 S4

页头：标签「商品图」/ 标题「灵感库」/ 描述「按分类翻提示词，看中哪条就带到工作台去出图。」统计「灵感库里一共 15045 条提示词。」左 220px 分类侧栏：「分类」+「全部」+ 约 11 项带灰色数量，选中蓝 soft 底。右内容区：搜索 placeholder「输入关键词，标题和正文都会搜。例如：白底 主图 模特」；筛选统计「按现在的条件找到 {count} 条。」+「清空筛选条件」；卡片瀑布流 3 列（标题多英文，无标题显示「（这条没写标题）」；正文前三行截断；左下分类小标；右下「{count} 处要填」；hover 浮起 + 主按钮「用它生成」；已下架降透明 + 标）；页底一次「提示词来自 YouMind 开源提示词库，按 CC BY 4.0 授权使用。」
详情抽屉 480px：标题 + 分类；示例图衬底 #17191E + 注记「这是别人用这条提示词出的示例图，不是用你的商品图出的，只能当参考。」失败态「示例图没加载出来。不影响使用这条提示词。」；「完整提示词（这段会带到工作台）」正文块；变量填空「这条提示词有几处要你自己填」+ 说明「下面填的内容会替换进提示词里。已经帮你填上了原作者的默认值，想换就直接改；留空的地方会原样保留那个花括号记号，带到工作台之后还能再改。」+ 未填完「还有 {count} 处没填。可以先带到工作台，在那里补完再提交。」；底部「用它生成」→ toast「提示词已经带到工作台了。」
空态两种：库空（运营版：「灵感库还是空的」+「提示词还没有导入进来。请管理员在这个页面点一下『立即同步』…在那之前，工作台里的『让 AI 推荐』也挑不出东西——它挑的就是这个库里的提示词。」管理员版：「还没有同步过。点上面那个『立即同步』，十几秒就能把一万多条提示词拉进来。」）；搜不到（「没有找到符合的提示词」+「换一个词试试，或者点『全部』看看别的分类。」+「清空筛选条件」）。
管理员同步面板（内容区顶部折叠卡）：「灵感库同步」+「把开源提示词库里的提示词拉到本地。只有管理员看得到这一块。」；「立即同步」；进度行「已经拉到 {fetched} 条 · 新增 {inserted} 条 · 更新 {updated} 条 · 没变化 {skipped} 条」；统计「现在库里有 {prompts} 条提示词、{categories} 个分类。」+「系统每 12 小时会自动同步一次，平时不用手动点。」；代理下拉（含「不使用代理（直连）」）+「一直失败多半是连不上外网：确认上面选的代理还能用，或者先改成『不使用代理』试一次。」

## 5. 我的图片 S5

页头「我的图片」/「你出过的图都收在这里，按任务归档，可以单张下载或打包下载。」批次列表「出图记录」时间倒序（批次名或「未命名批次」/提交时间/比例/徽章/「成功 N · 失败 N · 已停止 N」/实际花费/「打开这一批」「打包下载这一批」）。详情：图片网格衬底 #17191E 可切白底；hover「下载这张」「看大图」「用这张继续生成」；角标「第 {seq} 张」；失败占位卡 + 原因摘要；每张「这一张扣了 $1」。「用这张继续生成」toast「已经加到第一步的商品图里了，去上面改提示词和比例吧。」重复「这张图已经在第一步里了。」大图 lightbox：左右切换/「{width} × {height}」/本张提示词可复制/「下载这张」「用这张继续生成」/关闭；失败「这张图没加载出来。点一下重试；一直不行就刷新页面。」删除确认「删掉这张图？删了就找不回来了，已经花掉的钱不会退。」空态「还没有出过图。去『生成工作台』排第一批吧。」+「去工作台看看」。

## 6. 商品图设置 S6（v3 指定照抄本节）

单列表单分六段 + 右侧悬浮锚点目录。页头「商品图设置」/「出图比例、用哪个模型、一次最多出几张、单价，都在这一页改。改完点最下面的『保存设置』。」
字段样式规范：标签 + 控件 + hint（灰小字"这是干什么的"）；危险字段追加 danger 块（警告色 4px 左边线 + soft 底 + "填错会怎样"）。
六段：1.「出图」（比例：可拖拽排序标签编辑器，hint「运营在工作台第三步能选的比例，这里的顺序就是界面上按钮的顺序。」danger「一个都不留的话，运营选不出比例，一张图也提交不了。」；模型：placeholder「gpt-image-2」danger「填错了不会有任何提示，只会每一张都失败。」）2.「批量与速度」（单次最多出几张 danger 建议 50 上下；单张超时秒数默认 180；同时出几张默认 4 danger「别填超过 5——占满之后你自己点什么都很慢，但哪儿都不报错」+ 超建议值黄色确认条）3.「图片尺寸与计费档」（最长边默认 2048 danger「2048 及以下算 2K 档，超过就是 4K 档，4K 明显更贵」+ 价格预览表四列：比例/出图尺寸/计费档/单张价格，随值即时变化，表下「这是按你现在填的值算的，还没保存。」）4.「价格」（1K/2K/4K 三档单价 placeholder「还没测出来就留空」+「留空 = 价格待确认」；倍率 danger「填 0 会让工作台上每一批都显示成免费，运营会一口气排几十张。」；段首提示卡「还没填的档，会显示『价格待确认』……填 0 的话运营会以为不要钱。」）5.「出问题时找谁」（联系方式 placeholder「例如：微信 monica-designkit」danger「留空的话，运营看到的就只有『请联系管理员』，却不知道该找谁。」）6.「灵感库同步」只读（当前代理 +「这一项在『灵感库』那一页改，这里只能看。」+「去灵感库页面改」）。
保存栏吸底：「保存设置」+「放弃改动」+ 状态字（「有改动还没保存。」/「刚刚保存过（{time}）」/「没有改动，不用保存。」）；保存后回执卡两种（「有几项要重启才完全生效」信息蓝 /「保存好了，但有两句话要说」警告黄）。
页顶后端连通性卡：正常（绿点「后端已连通，地基没问题。」）/ 失败（红「连不上后端。」+「把这段信息截图给管理员即可，不用自己排查。」+ 折叠技术细节）/ 数据库挂（「后端活着，但连不上数据库——出图功能用不了。」）/ 配置缺失（「数据库正常，但有东西没配好——现在出不了图。」+ 清单）；「重新检查」。
异常整页态：「这个功能还没准备好」+「后端还没装好设置功能，多半是数据库没连上。出图会继续按现在已有的配置跑。把这句话截图给技术负责人即可。」
v3 追加：价格区视觉权重再高半档（默认 $1 可后期改价的操作入口）。

## 7. 全局组件与状态 S7（v3 指定照抄本节）

1. 报错块：中文一句话 + 小字「（错误码 {code}）」+「排障编号 {id}」+「把这一整块截图发给管理员，不用自己排查。」三示例：网络错误/余额不足/出图服务连不上（「连不上服务器。请检查一下网络，或者刷新页面再试；一直这样就把这句话截图给管理员。」）
2. toast 三态（成功/信息/失败），顶部居中 180ms 滑入。
3. 「申请额度」弹窗：正文「点一下会通知管理员给你加额度。可以顺便写一句你要做什么，方便管理员判断加多少。」placeholder「例如：这周要出夏季新款的详情图，大概 200 张」按钮「发给管理员」；回执「已经通知管理员了，请等管理员处理。」+「也可以直接联系管理员：{contact}」。
4. 空状态五张（统一插画风）：画布空/灵感库空/搜索无结果/我的图片空/连不上后端。
5. 骨架屏：图片卡/列表行/统计卡。
6. 键盘焦点走查样板：按钮/输入框/chips/图片卡。

## 9. 视觉资产细节（v3 引用部分）

### 9.3 图标体系
1.75px 线宽线性，20px（导航/按钮）与 16px（行内）两档，圆头端点，风格近 Lucide 但圆角大一档，深底反白可用。清单：生成工作台（画布+闪电）、灵感库（灯泡/书）、我的图片（相册）、个人资料、商品图设置（滑杆）、上传、下载、打包下载、移除、重试、停止、放大查看、继续生成（循环箭头+图）、申请额度、复制、搜索、筛选、同步、代理、健康检查（脉搏）、警告、成功、失败、关闭、展开/收起。

### 9.4 空状态插画五张
