## 第一章 · 使用总则

1. 三个 Claude Design 项目：**① 设计系统与品牌资产**、**② 产品端**（所有应用页面共一个项目）、**③ 官网**（三页共一个项目）。模型一律 Fable 5。
2. 每条提示词只做一屏；做下一屏先说"沿用本项目已确认的外壳与风格"。
3. 产品端每页**附现状截图**（1440px 宽逐页截）；官网**不允许**使用任何截图素材（D11）。
4. 迭代优先级：点击元素评论 > 调节滑块 > 追加对话；风格跑偏回设计系统改。
5. 文案铁律：金额一律 $；花钱按钮旁标价；"取消"只用于关弹窗；报错说"该怎么办"；禁用技术词。

**实施顺序**：logo（第二章）→ 设计系统（第三章）→ 外壳 → 工作台 → 全局组件 → 灵感库 → 我的图片 → 登录 → 设置 → 上游深色样板 → 官网三页 → 交接。

> ⚠ 2026-08-15 拍板：**本节的「顶栏 54 + 68px 图标工具栏」方案作废**，
> 外壳维持现状（上游 AppLayout 同款侧栏），只换深色皮。
> 保留的部分：全局余额不足提示条、移动 390px 轻量框架（看进度/下载）。

原文（作废的部分保留存档）：顶栏 54px（logo + 字标 + 小标签「商品图」+ 头像菜单）；左侧图标工具栏 68px（四项 + 管理员多「商品图设置」，选中态紫指示条 + soft 底）；内容区 1440px 居中；全局提示条（余额不足：警告 soft 底 +「可用余额不够了，还差 $X」+「申请额度」）；移动 390px 底部 64px 导航。

### 4.2 登录页 S2（`/login`）

左 · 产品舞台（55%）：大标题两行「商品图，运营自己出」/「AI 帮你配好提示词」；副标题「上传一次商品原图，换背景、配场景、按各平台要求出图。主图、详情图、活动海报一起做完，导出即可上架。」；主视觉 = 15 个电商平台标识球形环绕缓慢自转 + 后方 `--dk-glow` 氛围光；同时出静态排列版（减少动态效果/加载失败退路）；京东/拼多多/Amazon/Walmart 四家按现状用文字徽标。左下信任句：「出图前会先算一次预计花费，确认之后才开始跑，不会先斩后奏。」

右 · 登录表单（45%，垂直居中）：卡片标题「登录 DesignKit」；邮箱、密码（可见性切换）；主按钮「登录」；小字「没有账号？找管理员拿邀请码注册」。状态：字段错误 / 登录失败横条（「邮箱或密码不对，再试一次」及变体「密码改过了，登录状态失效，请重新登录」）/ 登录中。第二画面：邀请码注册（邮箱 + 密码 + 邀请码 + 「注册」）。

### 4.3 生成工作台 S3（`/workbench`，核心页）

studio 布局（中间画布 + 右侧 400px 配置区），不是步骤向导。一批典型 5~10 张 → 任务卡按大卡设计（一行 3~4 张）。

中间画布区：①页头（标签「商品图」/标题/描述 + 右上批次摘要「3 张商品图 × 3 条提示词 = 9 张」）②横排三格数据卡（本月出图/花费/余额 + 口径小字）③「第一步 · 选商品图」上传区（拖拽文案 + 格式辅助行 + 缩略图网格衬底 #17191E + 「上一轮出的图」角标 + 上传中 {percent}% + 失败可重传）④结果区空态（「出好的图会显示在这里」+ 细线条插画）⑤提交后批次进度面板（头部：批次名/状态徽章八态/「已完成 {done}/{total}」/计数行；右上「停止排队」次级危险按钮；等待提示「一张图大约要 20 秒…关掉网页也不影响出图」+ 弱提示「网络有点不稳，正在重连…」；大任务卡：缩略图骨架微光/「第 {seq} 张」/徽章/「这一张扣了 $1」/hover「下载」「用这张继续生成」/失败卡「重试这一张」+「第 2 次尝试 · 最多能试 3 次」；完成横幅三态 + 停止态追加句）。

右配置区（400px「出图设置」，独立滚动）：①「从灵感库带来的提示词」（仅带来时出现，可移除 + 排序说明小字）②「第二步 · 选分类、写商品特点，让 AI 配提示词」（说明句 + 分类下拉首项「全部分类（让 AI 自己判断）」+ 商品特点多行框 + 两句辅助 + 花钱主按钮「让 AI 推荐 · $0.09~$0.34」；运行态 = 按钮「AI 正在翻灵感库…」+ 四阶段进度（判分类→粗筛→细选→合成）+ 时长提示；结果卡「AI 给你的提示词」可编辑 + 判断说明 + 折叠「AI 参考了灵感库里这 5 条」+「重新推荐」标注再次收费）③「第三步 · 选出图比例」（五个真实宽高比选择块 + 角标「预估档位 2K」+ 补白边说明）④「花费预估」卡四态（够/不够+出路+申请额度/价格待确认/超上限）+「当前可用 $Y（可用 = 余额 − 排队占用）」⑤批次命名 ⑥通栏主按钮「提交出图」。

移动端只做进度查看视图。配套弹窗：确认提交/停止排队/重试（含超时警告）/AI 推荐四种失败内联提示。

### 4.4 灵感库 S4（`/inspiration`，示例图升为主角）

页头（标题/描述/统计 15045 条）；左分类侧栏 220px（「全部」+ 11 分类带数量，选中蓝 soft 底）；右内容区（搜索框 + 筛选统计 + 清空筛选；卡片瀑布流 3 列，示例图为主体衬底 #17191E、无图用细线条占位；图上分类小标、图下标题 +「{count} 处要填」；hover 浮起 + 主按钮「用它生成」；已下架降透明；页底 CC BY 4.0 一行）。详情抽屉 480px：大示例图置顶 + 注记 + 罕见失败态；「完整提示词（这段会带到工作台）」；变量填空区 + 未填完提示；底部「用它生成」→ toast。空态两种（库空运营版/管理员版；搜不到）。管理员同步面板折叠卡（立即同步/进度行/统计/12 小时自动/代理下拉/失败出路句）。

### 4.5 我的图片 S5（`/gallery`）

页头；批次列表「出图记录」（时间倒序批次卡：名/时间/比例/徽章/计数/实际花费/「打开这一批」「打包下载这一批」）；批次详情大图网格（一行 3~4 张，衬底可切白底；hover 下载/看大图/用这张继续生成；角标「第 {seq} 张」；每张「这一张扣了 $1」；失败占位卡 + 原因摘要）；「用这张继续生成」toast 两句；大图查看沉浸层（左右切换/尺寸/提示词可复制/下载/继续生成/关闭 + 失败态）；删除确认（「删掉这张图？删了就找不回来了，已经花掉的钱不会退。」）；空态 + 「去工作台看看」。

### 4.6 商品图设置 S6
