# DesignKit 官网（静态三页）

`index.html`（首页）/ `apply.html`（申请试用）/ `help.html`（帮助中心，双手册）。

- **全自包含**：零外链、零脚本依赖，任何静态文件服务器丢进去就能用
  （设计手册 7.3：先放 NAS 静态目录，公网阶段整目录迁移）。
- 权威副本在 `designkit/design/website/`（与 Claude Design「DesignKit 官网」
  项目同步）；改稿改那边，改完复制过来。
- `apply.html` 自带两版：表单版在上、降级联系卡在页底——静态托管没有表单
  接收端时，先把降级版换到上面（页内有注释标位）。
- 「联系方式占位」「二维码占位」上线前记得替换。
