01 · 宣言

DesignKit Dark 是全站唯一主题

浅色已彻底移除，不留切换开关。一套令牌同时覆盖两类场景： 运营每天长时间使用的工作台页面，和管理员打理系统的后台表单页。 深色的理由不是酷，是克制、护眼、信息密度友好——底色压暗， 层次靠描边与细微投影区分；电光紫只给「会发生事情」的动作按钮， 蓝色只给链接与选中，青色只给数据强调；商品图永远躺在中性灰衬底上， 不被蓝紫偏色污染。

全站唯一 · 无浅色 运营页 + 后台页 双场景 令牌名与代码一字不差 克制 · 护眼 · 密度友好
运营页 生成工作台 / 灵感库 / 我的图片 / 个人资料 —— 外壳维持上游同款侧栏，只换深色皮
后台页 商品图设置 + 上游全部后台页，按 S-UP 样板换肤；信息密度高一档（13px 主档）
登录页与官网 同一套令牌；仅这两处允许 --dk-glow 氛围光，正文区一律禁用
02 · 语义规矩

五条铁律，每条配对错示例

这些不是风格偏好，是文案层面的产品决策：违反任何一条都算走查不通过。

规矩 01

金额一律 $，不做汇率换算

系统底层余额和账单全是美元；界面与文档禁止出现「元」，否则会导致充错钱。金额用等宽数字、字重 600、主文字色（.dk-money）。

✓
预计花费 $12.00 · 当前可用 $36.00 关键数字绝不弱化：tabular-nums + 600 + 主文字色
✗
预计花费 12.3 元（约 $12） 出现「元」= 运营按人民币心算去充值，必然充错
规矩 02

花钱按钮旁标价

任何一次点击会扣钱的动作，价格小字直接缀在按钮文案后（.dk-button__price）；点之前就知道要花多少，不许「点了才知道」。

✓
重试同理：「重试等于重新出一张图，会重新收一次钱（这次 $1.00）。」
✗
不标价——运营点完才发现扣了钱，等于先斩后奏
规矩 03

「取消」只用于关弹窗，队列按钮叫「停止排队」

已经开始生成的图拦不住、会照常扣费。按钮叫「取消」而钱照扣，会被投诉「我明明取消了还扣我钱」；「停止排队」说的才是实情。

✓
弹窗写明：「还有 8 张没开始，停止后不再生成、也不扣费；正在生成的 4 张会跑完并正常扣费，图会保存在『我的图片』里。」
✗
运营会以为全都不扣费——「取消」只允许出现在关掉弹窗的动作上（如「再想想」「继续出图」）
规矩 04

报错说「该怎么办」

每条报错 = 中文一句话 + 下一步动作；技术细节收进小字（错误码、排障编号），给运营的指令永远是「截图给管理员，不用自己排查」。

✓
连不上服务器。
请检查一下网络，或者刷新页面再试；一直这样就把这句话截图给管理员。
错误码 502 · 排障编号 20260815-0042
✗
Error: connect ECONNREFUSED upstream 502 Bad Gateway 只有病状没有药方——运营分不清是自己错了还是系统坏了
规矩 05

运营页禁技术词，后台页允许必要技术词

API、令牌、网关、上游……这些词一个都不许出现在运营页面。后台管理页（商品图设置、上游后台）允许必要的技术词（模型名、代理地址），但报错仍然要带「怎么办」。

✓
「让 AI 推荐 · $0.09~$0.34」 「把这段信息截图给管理员即可，不用自己排查。」 动作说人话；出问题给出路
✗
「调用推荐 API」 「请检查 API 令牌是否过期」 运营页出现技术词 = 走查不通过

后台页尺度示例：「模型」字段 placeholder 写 gpt-image-2 可以；但它的 danger 说明仍是人话——「填错了不会有任何提示，只会每一张都失败。」

03 · 动效规范（9.5）

两个时长、一条曲线，能不动就不动

hover 用 120ms，页面切换与抽屉用 180ms，统一 cubic-bezier(0.2, 0, 0, 1)；此外只允许三种循环动效：骨架微光、生成中脉冲、AI 阶段呼吸。

时长与曲线

快出、缓收——前 20% 时间走完大半程，落点不弹跳。

hover · 120ms 页面切换 / 抽屉 · 180ms toast · 顶部居中 180ms 滑入

骨架微光 · 2s 周期

出图中的任务卡缩略位、加载中的列表都用它；微光从左向右匀速扫过。

底色 = 浮层色（--dk-surface-raised），高光只有 5% 白——深色底上的微光必须克制，不许扫成一道白光。「减少动态效果」时静止为纯色块。

生成中徽章 · 3 点脉冲

批次八态里只有「生成中」会动：三个点以 1.2s 周期交错明暗（各错开 0.2s）。

排队中 生成中 已完成 失败 已停止

其余状态一律静止。行内小场景可退用 .dk-badge--running 的单点脉冲，节奏同为 1.2s。「减少动态效果」时脉冲停止、文字保留。

「减少动态效果」降级

dk-dark.css 末尾的全局规则一刀切关掉全部动画与过渡，任何页面不许覆盖它。

@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation: none !important;
    transition: none !important;
  }
}
  • 登录页平台球停转，换静态排列版
  • 骨架屏微光停，保留静态色块占位
  • toast 滑入改淡入（由全局规则直接取消过渡）
  • 生成中徽章脉冲停，状态文字照常可读

其余动效规矩：AI 推荐等待的四阶段进度（判分类 → 粗筛 → 细选 → 合成）当前阶段用呼吸态，进度条不许假匀速走完；官网 Hero 线条描绘动效只播一次、不循环。
