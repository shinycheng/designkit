# DesignKit 项目计划书

> 更新日期：2026-08-08 ｜ 项目定位：对标美图设计室（designkit.cn）核心能力的 AI 商品图生成平台，
> 内部使用起步，架构上预留对外 SaaS 能力，提供标准 API 供 ERP 等系统对接。

---

## 一、项目现状（第一期已完成 ✅）

### 已交付的功能

| 模块 | 内容 | 状态 |
|---|---|---|
| 生成工作台 | 上传商品图（最多4张）→ 选提示词模板 → 填变量 → 设尺寸/张数/画质 → 异步生成 → 在线预览下载 | ✅ |
| 提示词模板库 | 分类管理、变量系统（文本/下拉）、JSON 批量导入导出、同名覆盖更新、启用停用 | ✅ |
| 生成记录 | 分页画廊、状态筛选、关键词搜索、详情抽屉、重新生成、删除 | ✅ |
| 生图引擎 | OpenAI 兼容接口（官方/国内中转均可，地址+Key+模型可配置）；mock 模拟模式（不花钱跑通全流程） | ✅ |
| 任务系统 | 数据库任务队列 + 线程池 worker，重启不丢任务、失败自动重试、原子领取（多进程安全） | ✅ |
| 对外 API | /api/v1/*：X-API-Key 鉴权、异步任务、三种给图方式（上传/URL/base64）、月额度限制、HMAC 签名回调 | ✅ |
| 账号安全 | 首次登录引导改密、登录限速防爆破、JWT 令牌可撤销、管理员/成员角色（成员账号暂无创建入口） | ✅ |
| 安全加固 | SSRF 防护（可配置内网开关，恒拦云元数据地址）、路径穿越防护、静态目录最小暴露、密钥打码 | ✅ |
| 部署 | 一键启动脚本（start.sh）、Docker 化（Dockerfile + compose）、依赖版本锁定 | ✅ |
| 文档 | 用户 README、ERP 对接文档（docs/erp-api.md）、在线调试页（/docs） | ✅ |

## 三、第二期：接入真实生图（下一步，等两项输入）

**目标**：从"模拟出图"切换到"真实 AI 出图"，并把你的提示词库灌进系统。

| # | 任务 | 谁来做 | 说明 |
|---|---|---|---|
| 2.1 | 提供提示词库 | **你** | 任何格式都行（Excel/Word/文本），发给 AI 助手即可 |
| 2.2 | 提示词库转换与导入 | AI 助手 | 转成系统 JSON 格式，梳理变量、分类、默认参数，批量导入 |
| 2.3 | 提供中转平台 API | **你** | API 地址 + Key；建议你亲自在「系统设置→生图服务」填写并点「测试连接」 |
| 2.4 | 真实出图调优 | AI 助手 + 你 | 用你的真实商品图试跑每类模板，效果不好的提示词逐个调优 |
| 2.5 | 成本核算 | 你 + AI 助手 | 按中转平台单价 × 平均张数估算月成本，必要时在系统里收紧默认张数/画质 |

**验收标准**：你的常用商品品类，每个核心模板都能稳定出可用的商品图。

**风险提示**：
- 中转平台质量参差：接口不稳定/排队慢/悄悄换模型。选平台时优先支持 `gpt-image-1`
  原生接口、按张计费透明的；系统已做自动重试和参数兼容重试，但平台跑路风险无法技术兜底，先小额充值。
- 生图费用：gpt-image 系列高画质单张成本明显高于低画质，建议日常用 medium、出正式图用 high。

## 四、第三期：部署上线（内部试用）

**目标**：从"你的电脑"搬到"云服务器"，团队成员和 ERP 都能访问。

| # | 任务 | 说明 |
|---|---|---|
| 3.1 | 购买服务器 | 国内云（阿里云/腾讯云）轻量服务器即可：2核4G 起步，约 ¥60-100/月；因为走国内中转 API，无需海外服务器 |
| 3.2 | 部署 | 服务器装 Docker → 上传项目 → `docker compose up -d`，10 分钟内完成 |
| 3.3 | 配置调整 | 「系统设置→对外访问地址」改成服务器地址；`.env` 里改端口/密钥（如需） |
| 3.4 | 安全基线 | 云防火墙只放行必要端口；若要公网访问建议套 HTTPS（Caddy/宝塔一键证书）；把「允许内网取图/回调」按需关闭 |
| 3.5 | 数据备份 | 每日定时备份 data/ 目录（文档已写明 WAL 注意事项）；建议同步一份到对象存储 |
| 3.6 | 域名（可选） | 国内服务器绑域名需 ICP 备案（约 1-2 周）；纯内部用 IP 访问可跳过 |

**验收标准**：手机/公司电脑都能打开平台正常生成；重启服务器后数据完好、任务恢复。

## 五、第四期：ERP 正式对接

**目标**：你的 ERP（或其他业务系统）自动调用平台批量生成商品图。

| # | 任务 | 说明 |
|---|---|---|
| 4.1 | 给对接方发资料 | 「API 对接」页创建专用密钥 + 发送 docs/erp-api.md，对方开发按文档接入 |
| 4.2 | 联调支持 | 常见问题：签名校验、回调地址连通性、图片 URL 有效期；平台侧日志可协助排查 |
| 4.3 | 额度与监控 | 给每个对接方设月额度防失控；观察 used_total 用量 |
| 4.4 | 按需增强 | 对接中可能提出的需求：批量提交接口、任务列表查询接口、图片自动回传对方 OSS 等，届时按优先级排 |

**验收标准**：ERP 下单 → 自动生成商品图 → 回调拿图入库，全程无人工干预。

## 六、第五期：功能扩展（按业务价值排序，做不做由你定）

对标美图设计室的其余能力，按「电商卖货价值 ÷ 开发成本」排序的建议顺序：

| 优先级 | 功能 | 价值 | 技术路径 | 预估规模 |
|---|---|---|---|---|
| ⭐⭐⭐ | 电商套图（一键多模板批量出图） | 一次出主图+场景图+细节图整套，直接可上架 | 现有引擎上加"模板组"概念，一次提交多任务 | 小 |
| ⭐⭐⭐ | 抠图/换背景/AI 消除 | 高频刚需 | gpt-image edits 已支持；提示词模板即可实现 80%，专业抠图可再接 remove.bg 类 API | 小-中 |
| ⭐⭐ | 模特穿戴图（服装/饰品上身） | 服装类目核心需求 | 提示词 + 参考图（现架构已支持多图输入），效果依赖模型能力 | 中 |
| ⭐⭐ | A+/详情页长图 | 亚马逊卖家需要 | 多图生成 + 排版拼接（Pillow 拼图） | 中 |
| ⭐ | 团队多成员账号 | 内部协作 | User 体系已预留，补成员管理页即可 | 小 |
| ⭐ | 批量任务（Excel 批量提交） | 大卖家效率 | 对外 API 已支持，做个网页批量入口 | 小 |
| 谨慎 | 带货短视频生成 | 效果好但成本高 | 需接视频模型（Seedance/可灵等），另立项评估 | 大 |
| 谨慎 | 海报模板编辑器 | 相当于再造一个稿定设计 | 不建议自研，可评估集成开源编辑器 | 很大 |

## 七、远期：对外 SaaS 化（若决定商业化）

架构已预留，届时需要补：

1. **多租户**：注册登录（手机号/微信）、租户隔离、成员邀请
2. **计费**：充值/套餐、按张计量（quota 字段已就绪）、账单
3. **合规**（国内运营的硬门槛，成本最高的部分）：
   - ICP 备案 + 增值电信业务许可（视模式）
   - **生成式 AI 内容合规**：内容审核（接入审核 API）、生成内容标识、算法备案
   - 用户协议/隐私政策
4. **基础设施**：SQLite → PostgreSQL、本地磁盘 → 对象存储(OSS) + CDN、监控告警
5. **数据库迁移工具**：引入 Alembic 管理表结构变更（多人多环境后必需）

> 建议：内部用出效果、ERP 跑顺之后，先以"给同行代生成"的轻模式验证商业价值，再投入 SaaS 化。

## 八、固定注意事项

- **备份**：`data/` 目录 = 全部数据。停服后整目录拷贝，或 `sqlite3 data/designkit.db ".backup 'x.db'"`
- **升级依赖**：requirements.txt 已锁版本，升级前先按 `tests/README.md` 跑一遍回归
- **密钥**：`.env`、`data/.secret_key`、API Key 明文只出现一次——都不要提交到 GitHub（.gitignore 已配好）
- **提示词是核心资产**：定期用「提示词模板」页的「导出」备份提示词库
